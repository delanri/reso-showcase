# Reso

**面向海外用户的 AI 伴侣 —— 记忆对用户可见、可改，记之前先问。独立开发。**

→ [reso.love](https://reso.love)（邀请制内测中）

大多数 AI 伴侣的记忆在后台：记了什么、记错了什么，用户看不到。Reso 把角色记住的每一件事写在记忆页上，用平常的话写，用户可以修改、删除；角色想记住新的事，先问用户。

> 技术栈：Vue 3 + Express + PostgreSQL + Qdrant · 用户自带模型 key（OpenAI / Anthropic / Gemini / DeepSeek / 自定义地址）
> 从零到上线不到一个月，之后持续迭代记忆系统和评测

## 功能一览

| 功能 | 实现 |
|---|---|
| 可见的记忆 | 记忆页列出角色记住的所有事，可编辑、删除 |
| 记之前先问 | 自建角色的新记忆进入「待确认」；同一件事换了说法时，新旧合成一条，用户选 **Remember this / Keep both / Discard** |
| 「记住这个」 | 用户直接说，立即记下，不等后台 |
| 画像 | 由全部记忆整理出一段「这个人是谁」 |
| 日记 | 每天在用户设定的时间，角色用自己的口吻写一篇 |
| 回忆 | 每次回复前组装画像、相关记忆、过去对话的片段和最近的小总结；偶尔主动想起旧事（闪回） |
| 角色 | 自建角色，或导入 SillyTavern 角色卡（PNG / JSON，含世界书）；官方角色 Casino 有自己的过去和关系阶段 |
| 自带模型 | 支持四家模型和自定义地址；后台整理工作可另选更便宜的模型 |
| 数据导出 | 聊天、记忆、画像、日记、自建角色卡打包成 zip；角色卡为标准格式 |
| 反馈 | Echo 反馈板：发帖、分类、投票 |

## 系统结构

```
浏览器（Vue 3，Cloudflare Pages）
        │
        ▼
Cloudflare ──▶ nginx ──▶ Express
                          ├ 正式服 / 测试服（两个独立进程）
                          ├ 每轮回复后：小总结 → 记忆候选 → 合并判断 → 画像
                          ├ 定时任务：日记
                          └ 调用用户自己的模型（四家统一成一套接口）
                                │
                ┌───────────────┼────────────────┐
           PostgreSQL        Qdrant          Jina Embeddings
     （用户、聊天、记忆）   （记忆向量）        （文本向量化）
```

## 记忆管线

1. **提取**：聊满一段、或用户隔一段时间回来时，后台从最近的对话里挑出值得长期记住的事
   - 只记用户自己说过、确认过的；角色的玩笑、猜测、叮嘱不算
   - 「明天」「周五」按用户时区换算成具体日期
   - 只在当天成立的事不记；密码、验证码、卡号、住址等不记
   - 用用户说话的语言写
2. **判断是不是同一件事**：先用向量找出相似的旧记忆，再让小模型逐条判断
3. **存储**：自建角色进入待确认 / 合并卡片；官方角色直接合并
4. **召回**：回复前按相关度取记忆，经过冷却、情绪匹配、来源去重等过滤，避免反复提同一件事
5. **整理**：画像随新记忆更新；日记每天生成

## 关键技术选择与取舍

- **记之前先问，而不是自动存**：记忆是用户的东西，记错了用户要能看见、能拦下。代价是用户要多点几下，所以官方角色走另一条路：悄悄合并，不打扰
- **「是不是同一件事」交给小模型判断**：向量相似度分不开。「在吃头孢」和「周五拔智齿」很像，却是两件事；「约了 7 号拔牙」和「改到 6 号」差了一个日期，却是同一件。所以向量只负责找候选，判断交给小模型；判断失败时当作不同，宁可多存一条，不错合
- **用户自带模型 key**：用户自己选模型、自己掌握花费，Reso 不承担调用成本。代价是要兼容各家的差异：会思考的模型会把输出额度全花在思考上，交回空答案，导致「记住这个」失效。后台调用因此统一关闭思考
- **测试服录像，正式服不录**：录像能把一次失败回放到具体哪一步，但它包含完整对话。真实用户的对话不录，只在测试服录假用户
- **自己做录像，而不是只用 Langfuse**：录像存进自己的数据库，后台直接看；Langfuse 留在测试服当对照

## 测试与观测

- **记忆回归评测**：测试服上让假用户与角色对话，埋入 20 个细节，结束后检查记住了几个。最新一轮 19/20
- **调用录像**：测试服记录每一轮里每次模型调用（回复、提取、合并、判断）的输入和输出，失败可以回放到出错的那一步，区分 Reso 的错和测试脚本的错
- **测试报告页**：管理后台查看每一轮的成绩和录像

## 部署与安全

- 正式服和测试服独立：进程、数据库、向量集合分开，改动先在测试服跑完整对话
- 一键部署：拉代码、依赖有变才安装、重启两服、确认健康
- 服务器只允许密钥登录；安全补丁自动安装；Cloudflare 到服务器全程加密；服务器、域名、代码托管账号均开启两步验证
- 每日自动体检，有异常发邮件；无异常时每周日发一封「这周都好」，收不到即说明服务器整体失联
- 用户的模型 key 以 AES-256-GCM 加密存储；登录用短期 + 长期两把 token；登录、聊天、导入、导出、后台分别限速
- 管理后台：用户、记忆、邀请码、系统状态、错误日志、数据统计
